# Outdoor Surplus USA: Variation D, Contractor

Concept rebuild for Outdoor Surplus USA (Castaic, California), a government vendor of playground systems, shade structures, shelters and site amenities. The layout follows the Baumeister template the client chose, rebuilt as static HTML/CSS/JS with no build step. The page is set to noindex.

Photographs are representative stock images. The quote form does not submit; see the TODO in script.js.
